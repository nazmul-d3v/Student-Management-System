# 🎓 Student Management System

A modern **Student Management System** built with **Python, Flask, SQLite, HTML, CSS, JavaScript, and Bootstrap**. This web application helps administrators manage student records efficiently through a clean and user-friendly interface.

## 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/nazmul-d3v/Student-Management-System.git
```

Go to the project folder

```bash
cd Student-Management-System
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Project

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
